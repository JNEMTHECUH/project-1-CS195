# project-1-CS195
  Project 1 - CS195 | Tic Tac Toe

  Description: 
  A web-based Tic Tac Toe game where the player (X)
  plays against a computer (O). The first to align
  three in a row wins. Includes win/draw detection
  and reset functionality.
